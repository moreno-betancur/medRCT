# medRCT
This repository has been subsumed by [https://github.com/T0ngChen/medRCT](https://github.com/T0ngChen/medRCT), which hosts the R package medRCT. This package builds on and expands the functionality of the R function medRCT() in this repository, to estimate interventional mediation effects that emulate a target RCT, per the following paper:

Moreno-Betancur M, Moran P, Becker D, Patton GC, Carlin JB. "Mediation effects that emulate a target randomised trial: Simulation-based evaluation of ill-defined interventions on multiple mediators". Statistical Methods in Medical Research 2021. 30(6):1395-1412[doi:10.1177/0962280221998409](https://doi.org/10.1177/0962280221998409)

See also:

Chen T, Dashti SG, Moreno-Betancur M. "medRCT: Causal mediation analysis estimating interventional effects mapped to a target trial in R". The Journal of Open Source Software 2025. 10(110), 8063 [https://doi.org/10.21105/joss.08063](https://doi.org/10.21105/joss.08063).
